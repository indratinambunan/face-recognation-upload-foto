# Face Recognition Upload Foto

Aplikasi berbasis Streamlit untuk melakukan face recognition menggunakan dataset gambar wajah.

## 📦 Library yang Dibutuhkan

* streamlit
* opencv-python-headless
* numpy
* pillow
* deepface
* tf-keras
* tensorflow

## 🚀 Cara Menjalankan Aplikasi

1. Clone repository:

```bash
git clone https://github.com/indratinambunan/face-recognation-upload-foto.git
cd face-recognation-upload-foto
```

2. Install library yang dibutuhkan:

```bash
pip install streamlit opencv-python-headless numpy pillow deepface tf-keras tensorflow
```

3. Jalankan aplikasi:

```bash
python -m streamlit run app.py
```

4. Aplikasi akan terbuka otomatis di browser dan siap digunakan.
