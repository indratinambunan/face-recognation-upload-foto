# Face Recognition Upload Foto
Aplikasi berbasis Streamlit untuk melakukan face recognition menggunakan dataset gambar wajah.

# Library yang dibutuhkan:
streamlit
opencv-python-headless
numpy
pillow
deepface
tf-keras
tensorflow

# Untuk run app :
1. Pilih app.py dan jalankan diterminal dengan cara : streamlit run app.py
2. Lalu tampilan app akan muncul dalam web browser dan dapat digunakan sesuai menu yang tersedia.
